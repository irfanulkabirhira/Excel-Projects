# Excel-Projects
This repository contains Excel-related projects aimed at enhancing data organization, analysis, and visualization. The project demonstrates various Excel functions, formatting techniques, and data manipulation strategies
📊 Vrinda Store Annual Sales Report 2022 (Excel Dashboard)

This Excel dashboard project presents a clean and insightful analysis of Vrinda Store’s sales performance for the year 2022. The focus of the report is to provide a snapshot of order activity, customer demographics, product categories, and regional sales trends — all using Excel’s native data visualization tools.

![image alt](https://github.com/irfanulkabirhira/Excel-Projects/blob/f1755dfaa80cfa0fb9c391dc5e66213e68432ed7/Project%20image.png)

🔍 Key Insights Covered in the Dashboard:

   Order vs Sales: Visual comparison of the number of orders and the corresponding revenue generated.

   Sales by Gender: A pie chart breakdown showing that Men contributed 63% and Women 37% of total sales.

   Order Status: All orders were 100% delivered, reflecting high fulfillment performance.

   Top 5 Sales States: Regional analysis of top-performing Indian states like Tamil Nadu, Maharashtra, and Rajasthan.

   Sales Channel: Currently, Amazon accounts for 100% of the sales, based on selected data.

   Orders by Age and Gender: Age-wise distribution showing how different age groups (Adult, Senior, Teenager) engaged across gender lines.

   Interactive Filters: Slicers for Month, Channel, and Product Category make the dashboard dynamic and user-friendly.

🧩 This project demonstrates how Excel can be used beyond spreadsheets — as a data visualization and reporting tool for retail business insights. It’s ideal for beginners in data analysis, business reporting, or Excel dashboarding.
